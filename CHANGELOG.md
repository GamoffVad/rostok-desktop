# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/). В каждой версии — изменения по сравнению с предыдущей.

## [1.2.1] — 2026-09-30

### Исправлено
- Подсказка в пустом поле (логин, пароль, поиск, даты, многострочные поля) начиналась левее, чем набранный текст: отступ поля применялся к тексту дважды, а к подсказке — один раз. Теперь подсказка стоит ровно там, где появится первая буква, — у всех полей, в том числе с нестандартным отступом.

### Добавлено
- Самопроверка интерфейса сравнивает положение подсказки и набранного текста у обычного, многострочного поля, поля пароля и даты — всего 45 проверок.

## [1.2.0] — 2026-09-30

### Добавлено
- **Вход по логину и паролю**: при запуске — форма входа, затем выбор рабочего пространства. В каждой базе есть **главный администратор** (при создании базы — логин admin, пароль admin); пока пароль стандартный, программа напоминает сменить его.
- **Роли «администратор» и «пользователь»** — вкладка «Администрирование → Пользователи» (только администраторам): добавление пользователей, роль, изменение логина и имени, сброс забытого пароля, удаление; владельцы рабочих пространств — пространство можно передать другому пользователю.
- **Вкладка «Учётная запись»**: логин, роль и смена своего пароля для входа.
- У пользователя может быть несколько рабочих пространств (хранилищ); он видит только свои.

### Изменено
- **У рабочих пространств больше нет паролей**: пространство принадлежит пользователю и открывается после входа одним нажатием.
- Администратор и главный администратор видят все пространства: свои открывают для работы, чужие — только для просмотра, с записью в журнал владельца (раньше это делал «руководитель»).
- Экран «Организация» показывает пространства с владельцами; кнопка на плашке просмотра возвращает в пространство, выбранное при входе, или к выбору пространства.
- Значок «Сменить пространство» в шапке открывает выбор пространства того же пользователя; «сменить пользователя» — на экране выбора.
- База обновляется до версии схемы 3 автоматически: каждое прежнее пространство становится пользователем с тем же паролем (логин — название пространства), руководитель — администратором.

### Удалено
- Пароли рабочих пространств и пароль администратора базы, вкладка «Администрирование → Организация» (роли теперь на вкладке «Пользователи»).

### Исправлено
- При наведении на логотип в шапке больше не появляется системный голубой фон (то же — у кнопки календаря в поле даты).

## [1.1.0] — 2026-09-30

### Добавлено
- **Руководитель (старший специалист)** видит рабочие пространства всех сотрудников базы без их паролей — только для просмотра.
- **Пароль администратора базы**: задаётся при создании первого пространства в новой базе или в «Администрирование → Организация»; можно сменить, зная текущий.
- **Вкладка «Администрирование → Организация»**: роль «Руководитель» у любого пространства назначается и снимается только с паролем администратора базы.
- **Экран «Организация»** (значок в шапке у руководителя): сводка по сотрудникам — групп, детей, срезов с данными, заполненность последнего среза, средний балл по речи на начало → конец, доля детей с положительной динамикой, последний вход; выгрузка сводки в Excel.
- **Режим просмотра** пространства сотрудника: те же экраны, отчёты, печать и выгрузки; кнопки, поля и отметки правки скрыты или только для чтения, хранилище ничего не записывает. Плашка «только чтение» и кнопка «Вернуться в своё пространство»; выбор группы, среза и раздела не меняет настройки сотрудника.
- **Журнал просмотров**: открытие пространства руководителем и сброс пароля записываются; сотрудник видит журнал в «Администрирование → Рабочее пространство».
- **Сброс забытого пароля** сотрудника руководителем — без старого пароля, с записью в журнал.
- Глава справки «Руководитель и журнал просмотров», раздел README «Старший специалист».
- Самопроверка интерфейса: сценарий руководителя (роль только с паролем администратора, просмотр без изменений, возврат, журнал, сброс пароля) — всего 36 проверок; проверки ядра — 31.

### Изменено
- База данных обновляется до версии схемы 2 автоматически при первом запуске: у пространств появляется роль, добавляется журнал просмотров; прежние данные и пароли не меняются.
- Выбор срезов по умолчанию для динамики перенесён в ядро — сводка организации и экран «Динамика» считают одинаково.

## [1.0.5] — 2026-09-28

### Исправлено
- Установщик на шаге «Установка» не копировал файлы: шаг рисовался дважды, и из-за этого установка останавливалась с незаметной ошибкой — полоса прогресса оставалась пустой, окно не закрывалось, а в конце нечего было запускать. Теперь установка идёт, прогресс виден, любая ошибка показывается в окне с кнопкой «Повторить».
- Серийный номер не сохранялся при повторной установке: он записывался только в самом конце установки. Теперь верный номер сохраняется сразу после проверки на шаге «Активация».

### Добавлено
- Самопроверка установщика: полная установка во временную папку, «Готово» и запуск установленной программы — выполняется при каждой сборке на GitHub.

## [1.0.4] — 2026-09-28

### Исправлено
- После установки с отметкой «Запустить «Росток»» программа не запускалась. Теперь установщик просит открыть программу рабочий стол Windows — как двойной щелчок по ярлыку: «Росток» запускается от имени обычного пользователя, установщик ничего не ждёт. Запасные способы — через Проводник и напрямую.

### Добавлено
- Ранее выданные ключ и серийный номер сохраняются: при повторной установке или обновлении шаг «Активация» сразу показывает ключ этого компьютера и подставляет номер, можно просто продолжить.
- Ключ компьютера запоминается сразу после генерации: установщик можно закрыть, пока администратор готовит номер, — при следующем запуске ключ уже будет показан.

## [1.0.3] — 2026-09-28

### Изменено
- Установщик компактнее: заголовки шагов меньше, поля и кнопки на шаге «Активация» — одной высоты 38 px, весь шаг помещается в окно без прокрутки.
- Отступы: кнопка «Сгенерировать ключ» больше не сливается с полем ключа (12 px), после пояснения шага — 20 px до полей.

### Исправлено
- На шаге «Размещение» кнопка выбора папки обрезалась справа, а поле папки было выше остальных полей.

## [1.0.2] — 2026-09-28

### Исправлено
- Установщик: кнопка «Готово» на последнем шаге ничего не делала. Теперь окно сразу закрывается, а «Росток» запускается от имени обычного пользователя (через Проводник, как с ярлыка), а не с правами администратора.

## [1.0.1] — 2026-09-28

### Исправлено
- «Ступеньки» на логотипе и иллюстрациях: изображения уменьшены под размер показа (логотип 128 px, иллюстрации 640 px), картинки масштабируются качественным фильтром.
- Двойная рамка на кнопке после щелчка мышью («Скопировано», «Выбрать файл»): рамка фокуса теперь появляется только при переходе с клавиатуры (Tab), как в веб-версии.

### Изменено
- Генератор серийных номеров вынесен в отдельный закрытый репозиторий администратора; в выпуске программы — только установщик.

## [1.0.0] — 2026-09-28

Первая версия настольного приложения: перенос веб-версии «Росток» 1.4.0 на WPF.

### Добавлено
- Все экраны веб-версии: дети, обследование, протокол группы, динамика, карта ребёнка (профиль, программа коррекции, заключение), отчёт для родителей, упражнения, администрирование (данные, словари, компоненты), справка.
- Библиотека компонентов `Rostok.Controls` — повторяет `src/ui` веб-версии: кнопки, поля, выпадающий список, поле даты с календарём, флажок, подсказки, выбор файла, уровни, графики, иконки.
- Рабочие пространства сотрудников с паролями: все данные и настройки хранятся только в своём пространстве.
- База данных SQLite в проекте; создаётся автоматически, если файла нет; работа в общей папке локальной сети.
- «Администрирование → Подключение»: путь к базе, проверка, создание файла; то же на экране входа.
- «Администрирование → Рабочее пространство»: название, смена пароля, удаление.
- Установщик с активацией по ключу компьютера (материнская плата) и серийному номеру, иллюстрации Higgsfield; удаление из «Программы и компоненты» без удаления базы.
- Проверка серийных номеров (подпись ECDSA P-256); сами номера выдаёт генератор администратора из отдельного закрытого репозитория.
- Печать и PDF через системный диалог; отчёт для родителей в .html с графиками; выгрузки Excel; резервная копия в формате веб-версии.

### Изменено по сравнению с веб-версией
- Значок администрирования — шестерёнка.
- Данные хранятся в базе рабочего пространства, а не в браузере.
